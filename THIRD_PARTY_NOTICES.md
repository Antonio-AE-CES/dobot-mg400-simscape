## MG400 model image

The file `mg400.jpg` was generated by the project authors from the
Simscape Multibody model of the DOBOT MG400.

The robot geometry represented in the image is based on the MG400 geometry
assets from the official DOBOT MG400_ROS repository described above.

## MG400 End Flange CAD model

The model optionally requires the official DOBOT MG400 end-flange CAD file:

`MG400_End_Flange_3D.stp`

This file is **not redistributed** with this repository.

Users should obtain the MG400 End Flange 3D model from the official DOBOT
MG400 product/download page:

https://www.dobot-robots.com/service/download-center

The downloaded file should be named:

`MG400_End_Flange_3D.stp`

and placed in the repository root next to:

`MG400_DigitalTwin_Interactive.slx`
